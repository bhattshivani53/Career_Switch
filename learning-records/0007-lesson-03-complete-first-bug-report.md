# Lesson 03 Complete — First Real Bug Report Raised

Shivani raised OJS-128 in YouTrack Issues for the SQL injection vulnerability on the Juice Shop login page. Bug was correctly typed as Bug, Priority Critical, moved to In Progress on the Agile board, and had 3 screenshots attached.

**Demonstrated correctly:**
- Bug life cycle navigation (New → In Progress on board)
- Correct Priority assessment (Critical for authentication bypass)
- Numbered, reproducible steps to reproduce
- Clear Expected vs Actual result distinction
- Multiple evidence screenshots (3 attachments)
- Used the correct project (OWASP Juice Shop)

**Two areas for improvement (communicated to learner):**
1. Bug title was descriptive of the symptom rather than naming the defect concisely. Should follow: [What is broken] + [under what condition] + [impact]. Correct form: "SQL injection in login email field bypasses authentication and grants admin account access"
2. Missing environment details (browser, OS, URL) — must be included in every bug report

**Implications:** Ready for Lesson 04 (Agile & Scrum). She understands the bug life cycle in practice, not just theory. She can now be introduced to sprint ceremonies and where QA fits within an Agile team — grounded in the YouTrack board she's already using.
