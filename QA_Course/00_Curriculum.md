# Junior QA Engineer — Interview Prep Course
### Designed for: Shivani Bhatt | Career Switch: Healthcare → IT/QA

---

## About This Course

You are a Healthcare Support Worker with a science background. That actually gives you a head start in QA — you already understand:
- Following **protocols** (like test cases)
- **Documenting** observations accurately (like bug reports)
- **Verifying outcomes** against expected results (like checking patient vitals against normal range)
- Working in **regulated, process-driven environments**

This course will translate those skills into QA language and add the technical knowledge you need.

|----------------------|---------------|

| Documenting patient observations | Writing bug reports with clear reproduction steps |
| Checking vitals against normal range | Verifying actual vs expected results |

| Handover notes between shifts | Test summary reports |
| Infection control checklists | Test checklists / regression suites |
