# QA Engineering Resources

## Knowledge

- [ISTQB Foundation Level Syllabus (free PDF)](https://www.istqb.org/certifications/certified-tester-foundation-level)
  The global standard for QA certification. The syllabus itself is free and covers every concept a Junior QA needs. Use for: authoritative definitions of all QA terms — if something is in here, it's the right way to say it in an interview.

- [Software Testing Help — Complete Guide](https://www.softwaretestinghelp.com/software-testing-introduction-free-training-series-day-1/)
  Structured, beginner-friendly tutorial series covering manual testing from scratch. Use for: reading between lessons to reinforce concepts. Particularly good for test case writing.

- [Guru99 — Software Testing Tutorial](https://www.guru99.com/software-testing.html)
  Free, visual, example-heavy tutorials. Use for: quick visual explanations of concepts like SDLC, bug life cycle, and test design techniques. Good companion to lessons.

- [Ministry of Testing — Learn](https://www.ministryoftesting.com/learn)
  The professional QA community's learning hub. Free articles and some paid courses. Use for: real-world QA perspectives, career advice, and community Q&A.

- [Postman Learning Center](https://learning.postman.com/docs/getting-started/overview/)
  Official Postman documentation. Use for: Module 07 (API testing). Follow the "Getting Started" path.

- [Atlassian JIRA Guides](https://www.atlassian.com/software/jira/guides)
  Official guides for using JIRA. Use for: Module 08 (Tools). The "Get started with JIRA" series is free and practical.

- [REST API concepts — MDN Web Docs](https://developer.mozilla.org/en-US/docs/Web/HTTP/Methods)
  Mozilla's reference for HTTP methods and status codes. Use for: Module 07. Authoritative and free.

- [Agile Manifesto + Scrum Guide](https://scrumguides.org/scrum-guide.html)
  The official Scrum Guide (free, 13 pages). Use for: Module 06. Reading the actual guide signals seriousness to interviewers.

## Wisdom (Communities)

- [r/QualityAssurance](https://www.reddit.com/r/QualityAssurance/)
  Active subreddit for QA professionals. Use for: asking career questions, reading about real-world QA problems, and seeing what tools/skills employers actually value.

- [Ministry of Testing — Community (The Club)](https://www.ministryoftesting.com/the-club)
  The most respected QA community online. Free membership tier available. Use for: posting test case reviews, getting feedback on bug reports, asking interview prep questions.

- [LinkedIn — QA / Software Testing groups](https://www.linkedin.com)
  Search "Software Testing" and "QA Engineer" groups. Use for: UK-specific QA job market insights, connecting with hiring managers, and following Senior QA voices.

- **Khushal (husband, Senior QA Analyst)** — Use for: real-world validation of everything learned. Ask him to review your test cases and bug reports before each mock interview. His feedback is the highest-signal resource available.
