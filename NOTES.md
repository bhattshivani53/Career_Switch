## Teaching Preferences & Style Notes

- Use healthcare analogies wherever possible — they land immediately and build confidence
- She is science-trained: she is comfortable with systematic thinking, protocols, and evidence
- Avoid heavy jargon dumps — introduce terms one at a time, always with a real example
- Each lesson should give her a tangible win quickly — confidence is important in a career switcher
- Tie every lesson back to "how would you answer this in a Junior QA interview?"

## Healthcare → QA Translation Frame

This is the core teaching advantage. Always show the parallel:
- Clinical protocols → test cases
- Incident/adverse event reports → bug reports
- Discharge checklist → test checklist / smoke test
- Escalating to senior nurse → raising a P1 bug in JIRA
- Patient observation documentation → test execution log
- Ward audit → QA audit / test coverage review
- "Expected vs actual patient outcome" → "expected vs actual result" in a test case
